```markdown
# 编译原理实验：中间代码生成

## 1. 实验目标

实现一个 C-- 语言到中间代码的翻译器。该程序读取符合 C-- 语法的源代码，输出遵循指定操作规范的三地址码形式的中间代码。通过本实验，掌握语法制导翻译、符号表管理、数组地址计算、函数调用约定以及控制流语句的翻译技术。

## 2. 总体假设（必做部分）

实验必须满足以下假设（取自教材 `4.3.1` 节）：

1. **无复杂常量**：输入中不会出现注释、八进制/十六进制整型常数、浮点型常数或浮点型变量。
2. **受限类型**：不会出现结构体类型的变量，不会出现高于一维的数组（即最多一维数组）。
3. **函数参数限制**：任何函数参数都只能为简单变量（即不能是数组或结构体）。
4. **无全局变量**：没有全局变量的使用，并且所有变量均不重名。
5. **函数返回类型限制**：函数不会返回结构体或数组类型的值。
6. **函数定义方式**：函数只会进行一次定义（没有函数声明）。
7. **输入正确性**：输入文件中不包含任何词法、语法或语义错误，函数内必有 `return` 语句。

> 注：上述假设为基础假设，选做部分将放宽其中第2条和第3条的限制。

## 3. 必做功能

基于上述假设，程序必须能够正确翻译以下语言特性：

### 3.1 基本数据类型与变量
- 仅支持 `int` 类型。
- 变量声明（如 `int a, b;`）。
- 局部变量的存储分配（无需显式 `DEC`，但数组除外）。

### 3.2 算术表达式
- 二元运算：`+` `-` `*` `/`
- 一元运算：`-`（取负）
- 优先级与结合性遵循 C 语言规则。
- 表达式求值生成临时变量，产生三地址码。

### 3.3 赋值语句
- 简单变量赋值：`a = b + c;`
- 数组元素赋值：`a[i] = e;`（其中 `a` 为一维数组）

### 3.4 一维数组
- 声明：`int a[10];`
- 访问：`a[exp]` 作为右值或左值。
- 内存分配：在中间代码中使用 `DEC` 指令为数组分配连续空间（大小 = 元素个数 × 4 字节）。
- 地址计算：基地址 + 下标 × 4。

### 3.5 控制流语句
- `if (cond) stmt`
- `if (cond) stmt1 else stmt2`
- `while (cond) stmt`
- 布尔表达式支持：`<` `<=` `>` `>=` `==` `!=` 以及 `&&`、`||`、`!`。
- 翻译策略：布尔表达式生成条件跳转指令（非短路求值也可，但跳转方式更符合教材示例）。

### 3.6 函数定义与调用
- 函数定义：`int func(int param1, int param2) { ... }`。
- 函数调用：`result = func(arg1, arg2);`。
- 参数传递：值调用（实参为简单变量或常数）。
- 返回值：`return expr;`。
- 预定义函数：
  - `read()`：无参数，返回 `int`。中间代码翻译为 `READ t1`。
  - `write(expr)`：一个 `int` 参数，返回 `int`（固定为 0）。中间代码翻译为 `WRITE x` 并生成 `place := #0`。

### 3.7 中间代码输出规范
- 每条指令一行，严格遵循教材表 4.6 的指令格式（关键字大写、常数前加 `#`、变量名大小写敏感）。
- 每个函数以 `FUNCTION 函数名:` 开头。
- 函数形参使用 `PARAM 参数名` 依次声明。
- 函数调用前使用 `ARG 实参`（顺序与 `PARAM` 相反）。
- 使用 `CALL` 调用函数并接收返回值。
- 为数组生成 `DEC 数组名 大小`（字节数）。

## 4. 选做功能（二选一，根据能力选择）

### 4.1 要求 4.1：支持结构体（本实验**不能完成**，仅作说明）
- 可实现结构体类型变量、成员访问（`.`）、结构体作为函数参数（传引用）。
- 若选择此要求，需放宽假设 2 和假设 3。

### 4.2 要求 4.2：一维数组作为函数参数 + 高维数组（**本实验要求完成**）

放宽假设 2 和假设 3，使输入中允许：

1. **一维数组作为函数参数**  
   - 形参声明如 `int arr[]`。  
   - 调用时传递数组名（自动传地址），中间代码生成 `ARG &数组名`。  
   - 被调函数中通过地址计算访问数组元素。

2. **高维数组类型的变量**  
   - 允许声明和使用二维及以上数组（如 `int a[2][3][4]`）。  
   - 高维数组**不能**作为函数参数或返回值。  
   - 需正确计算多维数组的地址：`base + i1*size1 + i2*size2 + ...`，并生成相应的 `DEC` 指令分配总空间。

**不要求实现的内容**：结构体（即选做 4.1 的内容不可出现，若输入包含结构体，程序应报错并退出）。

## 5. 输入与输出格式

### 5.1 输入
- 一个文本文件，内容为符合上述假设（及选做要求）的 C-- 源代码。
- 程序通过命令行参数接收输入文件名和输出文件名：
  ```
  ./cc input.c output.ir
  ```

### 5.2 输出
- 输出文件每行一条中间代码指令。
- 若输入包含不支持的结构体，输出错误信息：
  ```
  Error: Struct type is not supported.
  ```
- 若输入包含高维数组作为函数参数（违反选做 4.2 的限制），输出相应错误提示。

### 5.3 中间代码指令规范（表 4.6 关键指令）

| 语法                       | 说明                                 |
|---------------------------|--------------------------------------|
| `LABEL x:`                | 定义标号 `x`                          |
| `FUNCTION f:`             | 定义函数 `f`                          |
| `x := y`                  | 赋值                                 |
| `x := y + z`              | 加法（同样支持 `-` `*` `/`）          |
| `x := &y`                 | 取地址                               |
| `x := *y`                 | 读内存                               |
| `*x := y`                 | 写内存                               |
| `GOTO x`                  | 无条件跳转                           |
| `IF x relop y GOTO z`     | 条件跳转（relop: `<` `<=` `>` `>=` `==` `!=`） |
| `RETURN x`                | 返回 `x`（`x` 可为变量或 `#`常数）    |
| `DEC x size`              | 分配 `size` 字节（4的倍数）           |
| `ARG x`                   | 传递实参                             |
| `x := CALL f`             | 调用函数 `f`，返回值存入 `x`          |
| `PARAM x`                 | 声明形参                             |
| `READ x`                  | 从控制台读入整数到 `x`                |
| `WRITE x`                 | 输出整数 `x`                         |

> 注意：关键字必须大写；常数前必须加 `#`；变量名区分大小写；`ARG` 顺序与 `PARAM` 顺序相反。
