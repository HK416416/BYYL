# 编译原理实验四：目标代码生成 实验报告

## 一、实现功能

本程序实现了一个完整的 C-- 语言中间代码到 MIPS32 汇编代码的翻译器，包含以下功能：

### 1. 线形 IR 指令选择（宏扩展）
- 支持所有必做中间代码指令的翻译：赋值（`x := y`、`x := #k`、`x := y op z`）、内存操作（`x := *y`、`*x := y`）、控制流（`LABEL`、`GOTO`、`IF x relop y GOTO z`）、函数调用（`FUNCTION`、`PARAM`、`ARG`、`x := CALL f`、`RETURN x`）、`READ`/`WRITE`/`DEC`
- 支持加法常量折叠为 `addiu` 指令

### 2. 朴素寄存器分配
- 采用"栈分配"策略：所有变量统一在栈上分配空间，运算时通过 `lw` 加载到 `$t0`/`$t1` 临时寄存器，结果通过 `sw` 写回栈
- 函数调用参数在调整 `$sp` 之前预加载到临时寄存器，避免偏移量错误

### 3. MIPS 栈管理
- 被调用者 Prologue：分配栈帧、保存 `$ra`、复制 `$a0-$a3` 参数到栈
- 被调用者 Epilogue：恢复 `$ra`、回收栈帧、`jr $ra` 返回
- 调用者序列：预加载参数到临时寄存器 → 调整 `$sp`、保存 `$ra` → 设置 `$a0-$a3` → `jal` → 恢复 `$sp` 和 `$ra` → 存储返回值

### 4. 控制流翻译
- 条件分支翻译为 `beq`/`bne`/`blt`/`ble`/`bgt`/`bge` + `j` 指令
- 支持基本块标签跳转

### 5. 预定义函数
- `read()`：通过 SPIM 系统调用实现，先输出提示字符串，再读取整数
- `write(x)`：调用 SPIM `print_int` 和 `print_string` 系统调用

## 二、编译方法

```bash
cd Lab4.0/Code
make clean && make
```

编译生成 `parser` 可执行文件。运行方式：

```bash
./parser <input.cmm> <output.s>
```

## 三、实现亮点

- **IR 解析器**：采用 tokenize 方式解析三地址码，支持 16 种 IR 指令类型
- **调用序列**：在调整 `$sp` 前预加载参数值，避免栈偏移量计算错误
- **模块化设计**：新增 `codegen.c/h` 独立模块，通过 `codegen_generate()` 接口接收 IR 文件输出汇编代码
